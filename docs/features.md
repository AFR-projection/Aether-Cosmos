# 🎯 Features Overview

Complete feature list for Storage ByAFR.

---

## File Management

- **Upload & Download** — Drag-and-drop, multi-file, folder upload with structure preservation
- **File Preview** — Images, videos, audio, PDF, Office docs, text with syntax highlighting
- **Virtual Scrolling** — Handle thousands of files with `@tanstack/react-virtual`
- **Multi-Select** — Bulk operations (download, favorite, delete)
- **Type Filtering** — Quick filters for images, videos, documents, archives
- **Search** — Full-text search with PostgreSQL FTS
- **Favorites** — Bookmark files for quick access
- **Recycle Bin** — Soft-delete with restore and permanent delete

---

## Sharing & Collaboration

- **Share Links** — Expiration, access limits, view/edit permissions
- **Access Logging** — IP, device, browser, OS, location tracking
- **Folder Collaboration** — Shared folder access

---

## Security

- **End-to-End Encryption** — Optional client-side AES-GCM
- **2FA** — TOTP with recovery codes
- **Session Management** — View and revoke active sessions
- **Password Policy** — Minimum 10 characters, 3 character classes
- **Rate Limiting** — Login attempt throttling
