# Dashboard Override — Aether Cosmos ByAFR

Use the global vault palette, but increase information density to a practical workspace rhythm: 8px for compact metadata, 12–16px for row interactions, 20–24px for panels, and 28–32px only around the primary storage summary. Preserve a single visual focal point—the capacity view—then let inventory, recent files, and activity support it rather than compete with it.

The dashboard should read as a calm command center: layered neutral surfaces, restrained borders, a single accent treatment for primary actions, and semantic warning/destructive tones only when capacity crosses its configured threshold. Avoid rainbow metric cards, decorative charts without real data, and identical card hierarchy. Every value must retain a visible text equivalent; color and animation may reinforce state but never carry it alone.

Use a compact bento layout on desktop and a single, deliberate column on mobile. Recent files are direct deep links to their previews in `/files?select=…`; the dashboard is a launchpad, not a duplicate file browser. Motion should only explain refresh, capacity state, and list entrance; it must be disabled by the user’s reduced-motion preference.
